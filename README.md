# GeoTrace MAP
🇺🇸[English](doc/README_EN.md)

Настольный инструмент визуализации сетевых маршрутов на карте мира с
многоисточниковой геолокацией узлов.

![Карта трассировки](doc/screen001.png)

## Возможности

- **Трассировка** (`tracert`/`traceroute`) с парсингом прыжков, RTT (средний и
  минимальный) и отсечением приватных адресов.
- **Многоисточниковая геолокация с взвешенным голосованием**: независимые источники, указывающие на одно место, складывают
веса, поэтому несколько согласных слабых сигналов могут перевесить один
сильный, но одинокий. Источники и веса: ⚡ IXP/PeeringDB (5.0) · 📇 hostname PTR (4.0) · 🧠 обученная база (3.2) ·
🛰 два согласных GeoIP (2.4) · 📜 RIPEstat WHOIS (2.0) ·
📍 сосед по маршруту при почти равных RTT (1.6) · одиночный GeoIP (1.0).
GeoIP опрашивает двух независимых провайдеров (ipwho.is и ip-api.com),
их совпадение повышает вес. Для каждого узла выводится процент уверенности
с текстовой подсказкой.
- **Обнаружение anycast/CDN** (Cloudflare, Akamai, Fastly, CloudFront, Google,
  Azure…) с честной пометкой «вы на ближайшем edge-узле».
- **Аудит физики**: сверка географии с задержкой по скорости распространения
сигнала в оптоволокне (~100 км/мс с поправкой ×1.4 на непрямолинейность
реальных маршрутов); граница автокалибруется под конкретную трассировку по
уверенно определённым узлам. Невозможные hop'ы помечаются ⚠, ошибочно
обученные записи демотируются. Физически непротиворечивые узлы, напротив,
получают небольшую прибавку к уверенности. Результаты непрерывного пинга
подмешиваются обратно в проверку.
- **Обучение** (выкл / полуавто / авто) с предохранителями: промоция в
доверенные после 2+ наблюдений в разные дни и набора порога уверенности
(подтверждённые GeoIP наблюдения весят больше), TTL и очистка устаревших
записей, разрешение конфликтов, атомарная запись, физически невозможные
наблюдения отбрасываются, anycast не обучается.
- **Интерактивная карта** (Plotly): кластеризация близких узлов, кастомные
  тултипы, «пакеты» направления на композиторе (низкий CPU), пауза в простое.
- **Непрерывный пинг** любого узла с карты (перетаскиваемые панели),
  **TCP-ping фолбэк** когда ICMP блокирован, медиана RTT.
- **Экспорт**: CSV, JSON, автономный HTML, текстовый отчёт в буфер.
- **i18n** (RU/EN), тёмная/светлая темы, история целей, горячие клавиши,
  не зависящие от раскладки.

## Установка

Требуется **Python 3.8+**

## Платформа

Программа рассчитана на Windows: используются tracert,
subprocess.STARTUPINFO, os.startfile

### Пакеты pip
| Пакет | Установка | Зачем |
|-------|-----------|-------|
| `requests` | `pip install requests` | HTTP-запросы к GeoIP и RIPEstat WHOIS |

`urllib3` ставится автоматически как зависимость `requests`.
Всё остальное (`tkinter`, `subprocess`, `json`, `socket`, `http.server` и т.д.) —
стандартная библиотека Python, ставить ничего не нужно.

### tkinter (графический интерфейс)
- **Windows / macOS**: входит в официальный установщик Python.
- **Linux**: обычно ставится отдельно:
  - Debian/Ubuntu: `sudo apt install python3-tk`
  - Fedora: `sudo dnf install python3-tkinter`
  - Arch: `sudo pacman -S tk`

### Системные утилиты
- **Windows**: `tracert` и `ping` встроены; `curl` присутствует в Windows 10+
  (нужен только для TCP-фолбэка — при его отсутствии программа просто
  пропускает этот шаг).
- **Linux**: `sudo apt install traceroute iputils-ping curl`
  (`ping` обычно уже установлен).

### Быстрая проверка
```bash
python -c "import tkinter, requests; print('OK')"

- Windows: `tracert` встроен; `curl` обычно присутствует (нужен только для
  TCP-ping фолбэка).
- Linux: установите `traceroute` (`sudo apt install traceroute`).

### Запуск

```bash
python geotrace.py
```

Карта открывается в браузере по умолчанию и обновляется в реальном времени.

## Точность и ограничения

GeoIP-базы определяют город по *регистрации* пула, а не по физике, поэтому для
транзитных роутеров и anycast они системно неточны («московские пулы»,
«Сан-Франциско у Cloudflare»). GeoTrace компенсирует это hostname-кодами,
WHOIS, эвристикой соседей, аудитом задержек и обучением. Тем не менее
геолокация остаётся оценкой, а не истиной.
